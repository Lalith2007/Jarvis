# Capability Result

Standardizes all outputs from a capability.

## Schema
- `success`: Boolean indicating success.
- `status`: Execution status string.
- `result`: The primary returned artifact.
- `artifacts`: Any associated generated files/data.
- `metrics`: Telemetry and latencies.
- `logs`: Execution logs.
- `errors`: Specific exceptions.
- `diagnostics`: System traces.
