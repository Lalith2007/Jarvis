# JARVIS Engineering Manual

> **The official engineering specification for JARVIS — an AI Operating System.**

---

## Purpose

This directory contains the complete architectural specification for JARVIS.

These documents are the source of truth for the project.

All implementations—whether written by humans or AI coding agents—must conform to these specifications.

The specification is organized by subsystem rather than by technology so that each area can evolve independently while remaining consistent with the overall architecture.
