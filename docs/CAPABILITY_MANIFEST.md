# Capability Manifest

The static metadata object identifying every capability.

## Fields
- `id`, `name`, `version`, `author`, `description`, `category`
- `permissions`, `dependencies`
- `supported_inputs`, `supported_outputs`
- `configuration_schema`, `tags`, `enabled_by_default`
- Scheduling: `preferred_parallelism`, `exclusive_execution`, `estimated_memory`, `estimated_cpu`
