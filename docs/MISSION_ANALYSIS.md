# Mission Analysis

Mission Analysis is divided into 5 focused independent engines:
1. `MissionAnalyzer`: Graph completeness.
2. `PerformanceAnalyzer`: Concurrency vs sequential bottlenecks.
3. `FailureAnalyzer`: Retry exhaustion and failing capabilities.
4. `ResourceAnalyzer`: Latency and compute budgeting.
5. `CapabilityAnalyzer`: Capability breakdown and distribution.
