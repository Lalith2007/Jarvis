# Lesson Schema

Lessons are highly structured to ensure readability and downstream utility.

- `category`: Domain of the lesson (e.g., Performance, Reliability).
- `confidence`: Certainty score (0.0 to 1.0).
- `severity`: Severity impact (LOW to CRITICAL).
- `impact`: Human-readable impact description.
- `recommendation`: Actionable recommendation.
- `supporting_evidence`: Associated telemetry data justifying the lesson.
