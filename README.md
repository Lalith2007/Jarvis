# JARVIS AI Operating System

JARVIS is a personal AI Operating System designed to act as a unified intelligence layer across my digital life.

Unlike a traditional chatbot, JARVIS combines reasoning, memory, automation, and voice into a single modular system.

## Vision

Build an AI operating system capable of:

* Conversational AI powered by GLM 5.1
* Long-term memory using an Obsidian knowledge vault
* Voice interaction
* Local-first architecture
* Tool execution (Terminal, Browser, Python, GitHub, Gmail, Calendar)
* Autonomous task planning
* Personal knowledge retrieval
* Business automation
